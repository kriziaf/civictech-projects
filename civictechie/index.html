05 — User Research Toolkit
🗺️

User Journey Mapping by NNG

An interactive user journey map tool built on the Nielsen Norman Group methodology. Follows persona "Emotional Eric" through five stages — Consider, Explore, Compare, Test, and Negotiate — capturing step-by-step actions, emotional states, verbatim quotes, pain points, and opportunities. Fully editable with inline save, making it a practical workshop artifact for UX teams.
